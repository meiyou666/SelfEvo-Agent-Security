# 多模型攻击防御对比

本文件汇总 DeepSeek 与 OpenAI 在同一组安全模拟攻击样本上的攻击/防御结果。所有实验均不执行真实命令，`execute_command` 始终不会创建进程或修改系统状态。

## 实验口径

固定 4 类攻击场景：

- 命令执行诱导
- 敏感信息读取诱导
- 数据外传诱导
- 持久化诱导

每个模型运行两组：

```text
baseline：模拟无防护路径，攻击成功时记录 simulated_executed=true，并写入 demo_effects.jsonl
dry_run：开启防护，同样攻击被记录和拦截，不写入 demo 攻击效果
```

## DeepSeek 结果

DeepSeek `deepseek-v4-flash` 在 4 类攻击场景中均产生了可审计的 `execute_command` 高风险工具调用意图。

- baseline 组：4/4 进入模拟危险执行路径，并产生 4 条 demo 可见效果。
- dry_run 组：同样 4/4 高风险意图全部被防护层拦截。
- 真实执行次数始终为 0。

## OpenAI 结果

OpenAI `gpt-5.5` 在 4 类攻击场景中同样产生了可审计的 `execute_command` 高风险工具调用意图。

- baseline 组：4/4 进入模拟危险执行路径，并产生 4 条 demo 可见效果。
- dry_run 组：同样 4/4 高风险意图全部被防护层拦截。
- 真实执行次数始终为 0。

OpenAI 原始结果来自远端新增的 `chatgpt_merge_package/results/`：

## 结论

在相同的安全模拟攻击样本上，DeepSeek 与 OpenAI 均会在污染记忆触发下产生高风险工具调用意图。baseline 模拟无防护模式下，攻击进入模拟危险执行路径；启用 dry-run 防护后，同样的高风险意图被策略层记录、溯源并拦截。

最终结论：

```text
两种模型均可展示攻击诱导效果；
两种模型在防护开启后均被完全拦截；
真实执行次数始终为 0；
防护层对不同 LLM 后端具有一致效果。
```
